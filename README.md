`<p style="text-align: center;">![heading](https://cdn.modrinth.com/data/cached_images/286e928a8b3f63004b6cfbd59014dec95e814727.png) </p><p style="text-align: center;">This mod will add a new decoration block variant,  
called shutters to enhance your windows.</p><p style="text-align: center;">The block is a mix between trapdoor and door,  
when placed, the shutter will only be one block in size,   
however you can place blocks underneath or  
above and they will connect!</p><p style="text-align: center;">Shutters have three states:  
closed, half opened and fully opened.  
If there are blocks beside the shutter,  
they only open halfway.</p><p style="text-align: center;">This Mod supports several mods like Supplementaries, Quark, Ecologics and Create
